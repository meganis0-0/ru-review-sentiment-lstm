# Тональность отзывов на русском

Сеть читает отзыв и говорит, какой он: негативный, нейтральный или позитивный. Вместе с классом она показывает, насколько в этом уверена.

Сеть — двунаправленная LSTM: текст читается и слева направо, и справа налево. Цель проекта — F1-macro не ниже 0.80. На исходных метках корпуса проверка даёт 0.722. На банках, местах и фильмах, где метку ставит правило «претензия или похвала», та же сеть даёт 0.829 и на проверке, и на тесте. Обе версии лежат в проекте, и страница умеет между ними переключаться.

Код под лицензией MIT, copyright MEGANIS. Подробный рассказ — в `reports/report.md`. Карточки данных и модели — `DATASET_CARD.md` и `MODEL_CARD.md`.

## С чего начать

Если веса и тексты уже лежат рядом с репозиторием, достаточно поднять страницу.

```powershell
docker compose up app
```

Откроется http://localhost:8501. В списке две сети.

`corpus` училась на ста тысячах отзывов из восьми сфер и на тех метках, что пришли с корпусом. Её проверка — 0.722.

`rule` училась только на банках, местах и фильмах. Метку ей ставили по словам: больше претензии — негатив, больше похвалы — позитив, нет оценки или ничья — нейтрально. Проверка и тест — 0.829. Одежду, товары, продукты и аниме эта версия не видела.

Вставьте текст, выберите пример или загрузите `.txt` либо `.csv` с колонкой `text`. На экране будут класс и три вероятности.

Тот же ответ можно получить без страницы, запросом:

```powershell
docker compose up api
```

Описание запроса: http://localhost:8000/docs. Нужны поля `text` и `version` (`corpus` или `rule`). Пустой текст вернёт код 422.

Локально, без Docker:

```powershell
.\.venv\Scripts\python -m streamlit run app/main.py
.\.venv\Scripts\python -m uvicorn app.api:app --port 8000
```

## Слова по ходу текста

**Тональность.** Негатив, нейтрально или позитив.

**Метка.** Готовый ответ у отзыва, по которому сеть учится.

**Проверка и тест.** Две отложенные части. По проверке решают, стала ли сеть лучше. Тест открывают один раз, в самом конце.

**F1-macro.** Оценка, в которой у трёх классов равный вес. Если нейтральные отзывы даются плохо, цифра падает, даже когда негатив и позитив угаданы.

**Чекпоинт.** Файл с готовыми весами. Спрашивать сеть можно сразу по нему, без новой учёбы.

**Корпус.** Исходный набор отзывов. Вторая выборка, `rule`, собрана из его банков, мест и фильмов и размечена заново.

## Что лежит в репозитории

```text
app/            страница и программный доступ
configs/        настройки учёбы, сети и перебора параметров
data/           тексты: сырые, промежуточные, готовые к учёбе
docker/         образ
models/         копии двух чекпоинтов для хранилища данных
notebooks/      разбор состава выборки и ошибок
src/            учёба, перебор параметров, ответ на один отзыв
reports/        отчёт и сохранённые цифры

```

Тексты, файлы весов `*.pt` и журнал перебора `optuna.db` в git не входят: они большие. В репозитории лежат указатели `data.dvc`, `models/corpus.pt.dvc` и `models/rule.pt.dvc`. Сами файлы — в папке `storage/` рядом с проектом. Её копируют вручную, затем забирают данные:

```powershell
.\.venv\Scripts\dvc pull
```

Если чекпоинта в `checkpoints/` нет, страница берёт копию из `models/corpus.pt` или `models/rule.pt`.

## Установка

Нужен Python 3.11. Библиотеки ставятся только в папку `.venv` или внутрь образа Docker, не в системный Python.

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
.\.venv\Scripts\python -m pip install -e ".[dev,app,hpo,data]"
.\.venv\Scripts\pre-commit install
.\.venv\Scripts\dvc pull
```

Для учёбы нужен архив готовых векторов слов Navec. В git его нет. Файл кладут по пути из `configs/model.yaml`:

`data/external/navec_hudlit_v1_12B_500K_300d_100q.tar`

Проверить, что код в порядке:

```powershell

.\.venv\Scripts\black --check .
.\.venv\Scripts\isort --check-only .
.\.venv\Scripts\pytest
```

То же в контейнере: `docker compose run --rm checks`.

## Откуда отзывы

Тексты взяты из [Russian Sentiment Dataset](https://www.kaggle.com/datasets/mar1mba/russian-sentiment-dataset). Оставили восемь сфер: одежду, другие товары, продукты, места, фильмы, аниме, банки и банковское приложение. Новости и посты соцсетей убрали. В исходном файле `0` значит нейтрально, `1` — позитив, `2` — негатив.

Сначала из каждой пары «сфера и класс» взяли по 200 текстов, зерно 42. Потом обучающую часть добрали до 100 000: если в ячейке тексты кончались, брали больше из других сфер. Проверка и тест остались прежними, по 474 отзыва. Вместе 100 948. Словарь из 139 038 слов собран только по обучению. Сеть читает первые 200 слов отзыва.

Собрать выборку заново:

```powershell
.\.venv\Scripts\python -m src.data.collect --zip $env:USERPROFILE\Downloads\russian-sentiment-dataset.zip
.\.venv\Scripts\python -m src.data.prepare
.\.venv\Scripts\python -m src.data.validate
```

Вторая выборка — банки, места и фильмы с меткой по правилу. В обучении 31 491 отзыв, в проверке и тесте по 3 932.

```powershell
.\.venv\Scripts\python -m src.data.rule_label
```

Пятьдесят отзывов сверяли вручную. Инструкция лежит в `labeling/`, разбор состава — в `notebooks/01_eda.ipynb`. Разметку можно открыть в Label Studio:

```powershell
docker compose up label-studio
.\.venv\Scripts\python -m src.data.labeling
```

Страница разметки: http://localhost:8080.

## Обучение

Учёба корпуса читает `configs/train.yaml` и `configs/model.yaml` и перезаписывает `checkpoints/best.pt`. Там уже лежит готовая сеть: седьмая эпоха, на проверке F1-macro 0.722. Повторный запуск сотрёт этот файл.

```powershell
.\.venv\Scripts\python -m src.train
```

Вторая сеть пишет только в `checkpoints/rule/` и корпусный файл не трогает. На ней включены веса классов: позитивных отзывов в той выборке больше.

```powershell
.\.venv\Scripts\python -m src.train_rule
```

Та же корпусная учёба в Docker:

```powershell
docker compose run --rm train
```

Если в Docker есть видеокарта NVIDIA:

```powershell
docker compose -f docker-compose.yml -f docker-compose.gpu.yml run --rm train
```

## Перебор параметров

Его уже провели: 20 проб, журнал `ru-review-sentiment-lstm` в файле `optuna.db`. Меняли скорость обучения, dropout, размер памяти сети и размер порции отзывов. Лучшая проба — 13-я, на проверке F1-macro 0.661: скорость около 0.00252, dropout 0.172, память 128, порция 16. Готовый чекпоинт корпуса эти пробы не заменяли.

## Какие получились цифры

Сначала точка сравнения, ещё до LSTM. «Всегда отвечать позитивом» — это самый частый класс обучения. Логистическая регрессия смотрит только на набор слов, без порядка фразы, и учится на ста тысячах отзывов. Цифры ниже сняты с теста, зерно 42.

| Модель | Доля верных | F1-macro |
|---|---:|---:|
| Всегда позитив | 0.331 | 0.166 |
| Логистическая регрессия | 0.656 | 0.653 |

По классам регрессия на тесте даёт негатив 0.684, нейтрально 0.519, позитив 0.756. На проверке её F1-macro равен 0.683.

| Сеть | Где считали | F1-macro |
|---|---|---:|
| BiLSTM, исходные метки, 100 000 отзывов | проверка, 474 текста | 0.722 |
| BiLSTM, обучена на 3840 отзывах | тест, один проход | 0.679 |
| BiLSTM, правило претензия/похвала | проверка и тест, по 3932 | 0.829 |

Тест большой сети на ста тысячах отзывов заново не открывали. Строка 0.679 — более ранний чекпоинт. Число 0.829 — согласие с правилом претензия/похвала. С исходными метками Kaggle его не сравнивают. Подробности лежат в `reports/baseline.json`, `reports/target_metric.md` и `reports/rule_metric.json`.

```powershell
.\.venv\Scripts\python -m src.baseline
```

## Чего сеть не делает

Она оценивает текст отзыва. По её классу нельзя решать вопросы о человеке: кредит, найм, допуск к услуге.

На исходных метках цель 0.80 не взята. Нейтральный класс слабый, а сами метки шумные: в пилоте человек совпал с меткой корпуса в 31 случае из 50.

Версия `rule` не видела одежду, товары, продукты, аниме и приложение банка. Слова этих сфер для неё незнакомые. Цифру 0.829 на них не переносят.

Отзыв длиннее 200 слов обрезается с начала. Новости, комментарии и посты соцсетей в учёбу не входили.
